## 아이디어 목록

### ✅ 완료

- 북마크 수 조절 (최소 4개, 최대 8개, 2개 단위 +/- 버튼)
- 북마크 패널 고정 핀 버튼 (고정 시 다른 UI 뒤로)
- 북마크 링크 URL 자동 정규화 (`https://` 자동 추가)
- 유효하지 않은 북마크 링크 클릭 시 토스트 알림
- 운영자 앱 공지 토스트 (새 공지 올라올 때만 표시)
- 공지사항 마지막 업데이트 시각 표시
- 공지사항 제목 호버 0.5초 후 마퀴 스크롤 애니메이션
- 설정 알림 글래스모피즘 토스트로 통일
- 오프라인/에러 시 캐시 데이터 fallback
